# Plan: 다중 선택 일괄 편집 및 입력값 가드 레일 구축

이 계획은 다중 파트 선택 시의 편집 효율성을 높이고, 비정상적인 입력으로부터 엔진을 보호하는 시스템을 구축하는 데 초점이 맞춰져 있습니다.

## 1. 목적
*   **일괄 속성 편집**: 여러 파트를 선택하고 Inspector에서 값을 수정하면 선택된 모든 파트에 동시에 반영.
*   **기즈모 다중 드래그**: 여러 파트를 동시에 마우스로 드래그할 때 각 파트의 상대적 위치 관계를 유지하며 이동.
*   **입력 보호 (Guard Rails)**: 엔진이 처리할 수 없는 극단적인 값(음수 스케일, 비정상적인 인덱스 등)을 UI 수준에서 사전 차단.

## 2. 핵심 파일 및 컨텍스트
*   `src/editor/commands/property-commands.ts`: 단일/다중 속성 변경을 통합 지원하도록 개선.
*   `src/editor/gizmo.ts`: 다중 선택된 파트들에 대한 변위(Delta) 적용 로직 추가.
*   `src/editor/components/PropertyInspector.ts`: 입력값 유효성 검사 및 다중 선택 상태 UI 개선.
*   `src/editor/controller.ts`: `PROPERTY_CHANGED` 이벤트 처리 로직 최적화.

## 3. 상세 구현 단계

### 1단계: Property Command 및 Controller 고도화
*   [ ] `UpdatePropertyCommand`가 여러 파트의 인덱스를 배열로 받아 일괄 처리할 수 있도록 지원.
*   [ ] `controller.ts`의 `PROPERTY_CHANGED` 리스너에서 `BatchCommand`를 생성하는 로직을 단순화하고 성능 최적화.

### 2단계: 다중 선택 기즈모 드래그 (Group Transformation)
*   [ ] `CanvasGizmo`에서 드래그 시작 시 선택된 모든 파트의 현재 좌표를 캡처.
*   [ ] 드래그 중 마우스 이동량(Delta)을 모든 선택된 파트에 동일하게 적용하여 그룹 이동 구현.
*   [ ] 회전 및 스케일 지원 준비 (상대적 변환 행렬 개념 도입 검토).

### 3단계: 입력값 유효성 검사 및 가드 레일
*   [ ] `PropertyInspector`의 각 필드별 허용 범위 정의:
    *   Parent: 자기 자신 또는 후손 제외 (이미 구현됨, 강화 필요).
    *   Scale X/Y: 절대값 0 미만 방지 (0은 허용할 수 있으나 매우 작은 값으로 제한).
    *   Opacity: 0 ~ 1000 범위 강제.
    *   ImgCut Index: 사용 가능한 이미지 컷 범위를 벗어나지 않도록 검사.
*   [ ] 유효하지 않은 값 입력 시 시각적 피드백(빨간색 테두리 등) 및 적용 차단.

### 4단계: UX 개선
*   [ ] 다중 선택 시 Inspector에서 공통되지 않은 값은 "Mixed"로 표시하고, 입력 시에만 일괄 덮어쓰기 수행.
*   [ ] 기즈모 핸들링 시 시각적으로 그룹 전체가 이동하고 있음을 나타내는 바운딩 박스(선택 사항) 또는 가이드 라인 추가.

## 4. 검증 및 테스트 계획
*   **Multi-Part Edit Test**: 5개의 파트를 선택하고 Opacity를 500으로 변경했을 때 모든 파트가 정확히 500이 되는지 확인.
*   **Delta Drag Test**: (10, 10)과 (50, 50)에 위치한 두 파트를 +20만큼 드래그했을 때 (30, 30), (70, 70)으로 이동하는지 확인.
*   **Invalid Input Guard Test**: Scale에 -100 입력 시 적용되지 않고 1(최솟값) 또는 이전 값으로 유지되는지 확인.
