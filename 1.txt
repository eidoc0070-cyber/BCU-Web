## 2단계: `ShortcutManager` 모듈 분리

### 현재 상태 (`src/editor/controller.ts` L472~498)
```typescript
// controller.ts의 initGlobalEvents() 내부에 뒤엉켜 있음
window.addEventListener('keydown', (e) => {
  if (e.target instanceof HTMLInputElement) return;
  if (e.ctrlKey || e.metaKey) {
    if (e.key === 'z') { /* Undo */ }
    else if (e.key === 'y') { /* Redo */ }
  } else if (e.key === 'Delete' || e.key === 'Backspace') { /* 삭제 */ }
});
// + drag/drop, resize 이벤트가 같은 함수에 혼재
```

**문제**: `controller.ts`가 786줄. 단축키 로직이 드래그&드롭, 리사이즈 이벤트와 혼재.

### 신규 파일 설계: `src/editor/shortcut-manager.ts`

```typescript
// 설계 인터페이스 (틀)
type ShortcutHandler = (e: KeyboardEvent) => void;

interface ShortcutBinding {
  key: string;
  ctrl?: boolean;
  shift?: boolean;
  description: string;
  handler: ShortcutHandler;
}

class ShortcutManager {
  private bindings: ShortcutBinding[] = [];

  register(binding: ShortcutBinding): void   // 단축키 등록
  unregister(key: string): void              // 단축키 해제
  attach(target: Window): void              // 이벤트 리스너 부착
  detach(target: Window): void              // 이벤트 리스너 해제 (메모리 관리)
  list(): ShortcutBinding[]                 // 등록된 단축키 목록 반환
}
```

### 마이그레이션 작업
```
controller.ts initGlobalEvents()
  ├── keydown 리스너 전체 → ShortcutManager로 이전
  │     ├── Ctrl+Z  → Undo
  │     ├── Ctrl+Y  → Redo
  │     └── Delete/Backspace → Part 삭제
  └── resize / dragover / dragleave / drop → 그대로 유지 (무관)
```

### 작업 파일
| 파일 | 작업 |
|------|------|
| `src/editor/shortcut-manager.ts` | **신규 생성** |

## 3단계: 신규 단축키 추가

### 2단계 완료 후 `ShortcutManager.register()` 호출만으로 추가

#### 추가할 단축키 목록
| 단축키 | 동작 | 이벤트 |
|--------|------|--------|
| `Space` | 애니메이션 재생 / 일시정지 토글 | `eventBus.emit('PLAYBACK_TOGGLE')` |
| `ArrowLeft` | 타임라인 1프레임 뒤로 | `eventBus.emit('FRAME_STEP', { delta: -1 })` |
| `ArrowRight` | 타임라인 1프레임 앞으로 | `eventBus.emit('FRAME_STEP', { delta: +1 })` |
| `Home` | 타임라인 첫 프레임으로 | `eventBus.emit('FRAME_GOTO', { frame: 0 })` |
| `End` | 타임라인 마지막 프레임으로 | `eventBus.emit('FRAME_GOTO', { frame: -1 })` |

> [!NOTE]
> `eventBus`에 신규 이벤트 타입을 추가해야 할 수 있습니다.
> Timeline 컴포넌트의 현재 재생 상태 관리 방식을 먼저 확인 후 결정합니다.

### 작업 파일
| 파일 | 작업 |
|------|------|
| `src/editor/controller.ts` | `ShortcutManager`에 신규 단축키 `register()` 호출 추가 |
| `src/editor/event-bus.ts` (또는 types) | 신규 이벤트 타입 추가 (필요 시) |
| `tests/unit/shortcut-manager.test.ts` | 신규 단축키 동작 테스트 추가 |
